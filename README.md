# Bike Demand Prediction

## Project Overview

This project focuses on predicting bike rental demand using statistical analysis and supervised machine learning techniques.

The project analyzes different factors that may affect bike rental demand, such as time, temperature, weather conditions, seasons, and holidays.

## Objective

The main objectives of this project are:

- To understand the factors affecting bike rental demand.
- To perform data preprocessing and exploratory data analysis.
- To apply statistical analysis to the dataset.
- To build a supervised machine learning regression model.
- To evaluate the model's performance.
- To interpret the results obtained from the analysis.

## Dataset

The project uses the **Seoul Bike Sharing Demand Dataset**.

The dataset contains information about bike rentals along with environmental and seasonal factors.

The target variable is **Rented Bike Count**.

## Exploratory Data Analysis

The project includes visualizations and analysis such as:

- Distribution of bike rental demand
- Bike rental demand by hour
- Temperature vs. bike rental demand
- Holiday vs. non-holiday comparison
- Bike rental demand across seasons
- Correlation analysis using a heatmap

## Machine Learning

A supervised learning regression approach is used to predict bike rental demand based on the available features.

The model is evaluated using regression evaluation metrics.

## Conclusion

This project demonstrates the application of statistical analysis, data visualization, and supervised machine learning for analyzing and predicting bike rental demand.
